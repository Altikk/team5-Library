## 3. Порядок рассмотрения

1. Team-Lead выносит ЗИ-01 … ЗИ-04 и ЗИ-06 … ЗИ-08 на рабочее совещание 24.11.26 (поручение П-3 в [ExecutionControl.md](ExecutionControl.md)).
2. Запросы, меняющие сроки вех (ЗИ-04, ЗИ-06), согласуются с куратором.
3. После решения Team-Lead записывает его в этот реестр, вносит правки в затронутые документы и повышает их версии с записью «Изменения vX» (устав, раздел 11).
4. Запрос получает статус «Выполнен», когда правка есть в репозитории; ссылка на коммит или PR добавляется в столбец «Реализация».
