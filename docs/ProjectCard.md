# 3. Бизнес-цель
**Бизнес-цель**:  Создать авторитетную рекомендательную платформу за счет уникальной системы отзывов. Увеличить продажи и открыть дополнительные возможности для монетизации продукта.

**Vision Statement** (подробнее — [Vision.md](Vision.md)):
> Для читателей, выбирающих следующую книгу, которым нужно быстро найти честное и содержательное мнение, а не накрученную среднюю оценку, продукт КнигоПоиск — это веб-сервис выбора книг и отзывов, который первыми показывает отзывы авторов с заслуженной репутацией благодаря прозрачной системе опыта и рангов. В отличие от LiveLib и Goodreads, где все отзывы равны и легко накручиваются, наш продукт ранжирует отзывы по рангу автора, а сам рост ранга защищён от накрутки задержкой начисления, лимитами и модерацией.

# 4. Границы MVP
- Регистрация и авторизация пользователей, роли (гость, читатель, модератор, администратор).
- Каталог книг с поиском и базовой фильтрацией (жанр, автор, год).
- Карточка книги: описание, обложка, средний рейтинг.
- Написание, редактирование и удаление отзыва.
- Лайки отзывов.
- Система накопления опыта и присвоения ранга пользователя с защитой от накрутки.
- Отображение ранга автора рядом с отзывом.
- Сортировка отзывов по рангу и дате.
- Публичная страница правил рангов и базовый профиль с прогрессом до следующего ранга.
- Работа модерации: жалобы, очередь, скрытие/удаление, штрафы.
- Интеграция с 1С: выгрузка каталога и получение отчёта по продажам.

**Не входит:** мобильное приложение, продажа книг и читалка, платная подписка, соцлента и личные сообщения, AI-рекомендации (подробнее — [Vision.md](Vision.md), раздел 5).

## 5.16 Правила рангов и опыта

Эти правила публикуются на странице «Как работают ранги». Пороги хранятся в `ranks`, значения опыта — в конфигурации сервиса.

| RankID | Title       | MinExperience |
| ------ | ----------- | ------------- |
| 1      | Новичок     | 0             |
| 2      | Читатель    | 100           |
| 3      | Книголюб    | 300           |
| 4      | Рецензент   | 700           |
| 5      | Знаток      | 1500          |
| 6      | Эксперт     | 3000          |

**«Высшие ранги»** в метриках и отчётах — ранги 5–6 (Знаток, Эксперт).

| Событие | Опыт | Условия |
| ------- | ---- | ------- |
| Отзыв 300–999 символов | +20 | Запись `pending`, подтверждается через 72 ч, если отзыв `active` |
| Отзыв ≥ 1000 символов | +35 | То же |
| Отзыв < 300 символов или оценка без текста | 0 | Публикуется, но опыт не начисляется |
| Получен лайк | +2 | Начисляется сразу (`confirmed`). Не более 10 XP в сутки от одного и того же пользователя; лайк своего отзыва невозможен. Снятие лайка — запись −2 |
| Штраф модератора (`penalty`) | −50 | Плюс отмена (`cancelled`) неподтверждённого опыта за этот отзыв |
| Суточный лимит | ≤ 100 XP | Суммарно по всем положительным начислениям одному пользователю за сутки |

Ранг пересчитывается при каждом подтверждении или списании опыта и может понижаться после штрафа.

# 6. Риски и допущения

**Риски:**

| Риск                                                     | Вероятность | Влияние | Меры                                            |
| -------------------------------------------------------- | ----------- | ------- | ----------------------------------------------- |
| Накрутка опыта и рангов                                  | Высокая     | Высокое | Задержка начисления 72 ч, суточный лимит 100 XP, лимит лайков, модерация, штрафы |
| Субъективность и предвзятость отзывов                    | Высокая     | Среднее | Ранжирование, жалобы, прозрачные правила рангов (раздел 5.16) |
| Холодный старт (мало отзывов и опытных авторов)          | Высокая     | Среднее | Тестовые данные на демо-стенде, импорт каталога из открытых API |
| Технические сбои при росте нагрузки                      | Средняя     | Среднее | Кэширование, индексы, мониторинг                |
| Задержка интеграции с 1С                                 | Средняя     | Среднее | Ранний согласованный формат обмена (JSON), заглушка 1С для тестов |
| Юридические риски (персональные данные, авторские права) | Средняя     | Высокое | Пользовательское соглашение, права на обложки   |

**Допущения:**
- Пользователи готовы писать отзывы ради роста ранга.
- Ранг авторитетен для читателей при выборе книги.
- Данные о книгах можно получить из открытых источников или API.
