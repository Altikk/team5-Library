Каждый контейнер C4 Container Diagram — это пакет работ со своим результатом, требованиями, оценкой и владельцем (A в матрице RACI). Оценка укрупнённая, точность ±30 %. Should и Could (Email-сервис, импорт из открытых API) в план MVP не включены: это резерв содержания на второй семестр.

## 2. Матрица ответственности RACI

R — выполняет, A — отвечает за результат, C — консультирует, I — информируется. В каждой строке ровно одна A. Эта матрица заменяет матрицу по этапам из раздела 7 [ProjectCard.md](ProjectCard.md) (запрос ЗИ-01).

| Пакет работ | Team-Lead | Full-stack API | Full-stack Data | Full-stack UI | 1C-Developer |
| --- | --- | --- | --- | --- | --- |
| 1. Веб-клиент | I | C | I | A/R | I |
| 2. API-сервер | I | A/R | C | C | C |
| 3. Фоновый обработчик | I | C | A/R | I | I |
| 4. База данных | I | C | A/R | I | C |
| 5. Интеграция с 1С | I | C | C | I | A/R |
| 6.1. Архитектура и ADR | C | A/R | C | C | C |
| 6.2. Демо-стенд и развёртывание | I | C | A/R | C | I |
| 6.3. Тестирование и приёмка | A | R | R | R | R |
| 6.4. Требования, изменения, план, документация | A/R | C | C | C | C |

**Ориентировочная нагрузка (без координации):** Full-stack API — 50 ч (пакеты 2 и 6.1), Full-stack Data — 36 ч (3, 4, 6.2), Full-stack UI — 40 ч, 1C-Developer — 20 ч, Team-Lead — 8 ч плюс координация. Часы пакета 6.3 делятся между исполнителями по задачам на практике 6.
