| **Поле** | **Описание** |
| -------- | ------------ |
| Версия   | v2.0         |
| Дата     | 20.10.26     |

**Изменения v2.0** (по итогам анализа аналогов и сверки с Vision):
- «Система лайков» перенесена из Should в Must, потому что опыт за лайки уже входил в Must.
- Минимальная форма жалобы перенесена в Must, потому что модерация в Must обрабатывает жалобы.
- «Роли пользователей» перенесены в Must: без роли модератора модерация невозможна, а таблица `roles` уже есть в модели данных MVP.
- Добавлена публичная страница правил рангов (инсайт 5).
- Базовый профиль и интеграция с 1С перенесены в Must, потому что они запланированы в первом семестре (этапы 6 и 7 календаря).
- Для каждого пункта Must указаны коды Use Case и инсайтов для трассировки.

## Should have (очень важно, но можно чуть позже)

- **Расширенный личный кабинет**: история отзывов, журнал начислений опыта, редактирование профиля.
- **Восстановление пароля** и подтверждение email.
- **Фильтры и поиск в очереди модерации**, статистика модератора.
- **Пагинация и кэширование** каталога и списка отзывов.
- **Администрирование каталога** через интерфейс (сейчас наполнение идёт миграциями).
- **Расширенная интеграция с 1С**: автоматическая выгрузка аналитики продаж по расписанию, актуализация каталога.

## Could have (будет полезно, но не критично)

- **Рекомендации книг** на основе жанров и истории просмотров (простая эвристика, без ML).
- **Достижения и бейджи** (например, «Топ-рецензент месяца»).
- **Поиск по полнотекстовому совпадению** (PostgreSQL full-text / Elastic).
- **Рейтинг авторов отзывов (leaderboard)** и подписка на автора.
- **Уведомления** о новых отзывах/повышении ранга (email / in-app).
- **Импорт данных о книгах** из открытых API (Google Books, Open Library).

## Won't have (исключено из ближайших планов)

- Мобильное приложение (только веб-версия на MVP-этапе).
- Платная подписка и внутренняя валюта.
- AI-рекомендации и генерация обзоров.
- Встроенная читалка и скачивание книг.
- Торговая площадка (продажа книг напрямую через сервис).
- Социальная лента и личные сообщения между пользователями.
