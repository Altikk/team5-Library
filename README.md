# КнигоПоиск (Онлайн сервис выбора книг с помощью уникальной системы оценки)

## **🦖 О проекте**
Данный проект решает **проблему сложного выбора** книги для чтения. С помощью **уникальной системы отзывов**, найти хорошее произведение становится намного **проще**! Вместо обычных звезд и цифр, сервис использует систему накопления **опыта** и повышения **ранга** пользователя, чтобы другие читатели видели, что данный человек **разбирается** в том, о чем пишет!
